# 项目目标

## 产品目标

为科研人员提供可追溯、可更新的会议与期刊信息工具，首版覆盖投稿截止日期、资质、审稿制度及相关证据。

## 交付形态

- 开源、本地自托管的桌面/本地 Web 工具，用户从 GitHub 仓库下载后在自己的电脑运行，不针对公网部署。
- 用户使用自己的 API Key（如 Web Search、LLM），凭据只保存在用户本地，不内置任何密钥。
- 仓库需提供 README、LICENSE、示例配置和免责声明，保证任何用户都能自行下载运行。

## 当前范围

- 首个且唯一开放的领域为 Computer Vision（计算机视觉）。
- 核心系统保持领域无关，通过领域配置包扩展。
- 首次流水线实验只实现领域配置、三条会议基础数据和自动校验。
- 首次实验不采集实时截止日期，不开发前端，不接入数据库，不引入第三方依赖。

## 信息原则

- 官方来源优先。
- 关键字段必须保留来源和最后核验时间。
- 官方事实、可核验统计、个人经验和模型摘要分开建模。
- 实时信息未经核验不得进入正式数据。

## M3：可运行 Web MVP

- 提供 Computer Vision 会议总览、搜索筛选和来源详情。
- 提供用户自定义目标截止日期的六阶段投稿倒排计划。
- 计划在浏览器 localStorage 持久化，可勾选进度、删除并导出 ICS。
- 本轮使用 React、TypeScript 和 Vite；不引入账号、后端或数据库。
- 正式 Venue 数据未包含的实时截止日期、资质和审稿信息保持待核验，不用示例数据冒充。

## 双模型分工

- 强力模型：规划、架构、任务契约、验收、异常处理和决策沉淀。
- 日用执行模型：在限定路径内完成小任务，运行测试并报告偏差。
- 人类：保留范围调整、外部发布和正式数据入库的最终决定权。
